# HeyGen Avatar OAuth — архитектура

## Обзор

Проект состоит из инструкции агента, самостоятельного Node.js-клиента и тестов.
Агент принимает запрос пользователя и вызывает только разрешённую команду клиента.
Клиент локально проверяет вход, файлы и подтверждение, затем обращается к официальному
HeyGen CLI.

## Поток данных

```text
аудио или утверждённый текст пользователя
              │
              ▼
      SKILL.md: правила и согласие
              │
      ┌───────┴────────┐
      │                │
  готовое аудио      текст
      │                │
      │                ▼
      │     scripts/elevenlabs-client.mjs
      │       ├─ точный текст + выбранный voice ID
      │       ├─ один разрешённый запрос ElevenLabs
      │       └─ проверенный локальный MP3-кэш
      │                │
      └───────┬────────┘
              ▼
 scripts/heygen-client.mjs
  ├─ проверка OAuth + subscription
  ├─ локальная подготовка аудио через FFmpeg
  ├─ выбор свежего личного look по group ID и формату
  ├─ один разрешённый вызов HeyGen CLI
  └─ скачивание и проверка MP4
              │
              ▼
       локальный готовый файл
```

## Части

| Часть | Путь | Назначение |
|---|---|---|
| Инструкция агента | `SKILL.md` | Когда использовать скилл и где обязательна остановка |
| Клиент | `scripts/heygen-client.mjs` | Проверки, каталог, создание, ожидание и скачивание |
| Синтез речи | `scripts/elevenlabs-client.mjs` | Текст, голос ElevenLabs, защита от повторного списания и MP3-кэш |
| Установщик | `scripts/install.sh` | Копирует только публичные файлы в каталог Codex или Claude Code |
| Функциональные тесты | `tests/heygen-client.test.mjs` | Проверяют контракт клиента без живого HeyGen |
| Тесты синтеза | `tests/elevenlabs-client.test.mjs` | Проверяют точный текст, согласие и кэш без обращения к ElevenLabs |
| Публикационные тесты | `tests/publication.test.mjs` | Проверяют комплект, обезличивание и установку |

## Локальное состояние

- Конфигурация: `~/.config/heygen-avatar-oauth/config.json`.
- Незавершённые рендеры: `~/.local/state/heygen-avatar-oauth/jobs/`.
- Кэш синтеза ElevenLabs: `~/.local/state/heygen-avatar-oauth/elevenlabs/`.
- OAuth: стандартный файл HeyGen CLI `~/.heygen/credentials`.

Эти данные не входят в репозиторий и не копируются установщиком.
Локальная конфигурация, состояние, превью голоса и готовые ролики сохраняются с
закрытыми правами владельца.

## Внешние зависимости

| Компонент | Для чего нужен |
|---|---|
| HeyGen CLI | OAuth и операции с аккаунтом HeyGen |
| ElevenLabs API | Синтез речи из текста голосом пользователя; только для текстового режима |
| FFmpeg | Нормализация аудио |
| FFprobe | Проверка медиафайлов |
| Node.js 20+ | Выполнение клиента и тестов |

Для готового аудио переменные окружения не требуются. Текстовый режим читает
`ELEVENLABS_API` (или `ELEVENLABS_API_KEY`) и `ELEVENLABS_VOICE_ID`. Значения не
сохраняются в репозитории. `HEYGEN_API_KEY` намеренно удаляется перед запуском HeyGen CLI.
