# Как внести вклад

## Перед изменением

1. Не добавляйте реальные токены, OAuth-файлы, ID аккаунта или пользовательские медиа.
2. Для нового поведения сначала добавьте тест, который воспроизводит нужный контракт.
3. Не ослабляйте обязательное подтверждение расхода кредитов.
4. Не добавляйте режим API-ключа: назначение проекта — OAuth и подписка.

## Проверка

```bash
npm ci
npm run verify
```

Все тесты должны проходить без обращения к живому аккаунту HeyGen и без расхода
кредитов. Для исправления безопасности добавьте отрицательный тест с проблемным
вводом и соседний положительный сценарий.

## Документация

Пользовательские инструкции пишутся по-русски и простым языком. Если меняется
команда, зависимость или поток данных, одновременно обновите `README.md`,
`ARCHITECTURE.md`, `TESTING.md` и `CHANGELOG.md`.
