# Правила проекта heygen-avatar-oauth

## Назначение

Это публичный русскоязычный скилл для Codex и Claude Code. Он управляет личными
аватарами HeyGen через браузерный OAuth-вход и кредиты подписки без API-ключа.

## Перед работой

1. Прочитайте `README.md`, `ARCHITECTURE.md` и `MEMORY.md`, если локальная память существует.
2. Проверьте `git status --short` и последний дневник в `memory/`.
3. Не добавляйте реальные OAuth-файлы, ID аккаунта, пользовательские медиа и остатки кредитов.
4. Новое поведение начинайте с падающего теста.

## Неподвижные правила безопасности

- Не использовать и не запрашивать `HEYGEN_API_KEY`.
- Не обходить OAuth, consent Digital Twin и ограничения подписки.
- Не запускать создание аватара или видео без явного разрешения пользователя.
- Один запрос разрешает одну платную операцию; при таймауте продолжать существующий ID.
- Живую запись пользователя не заменять синтетическим голосом.
- Не публиковать конфигурацию, OAuth, реальные ID и медиа.

## Команды проверки

```bash
npm ci
npm run verify
```

## Документация — держать в синхроне

Если меняется команда или пользовательский поток, обновите `README.md` и `SKILL.md`.
Если меняется устройство клиента — `ARCHITECTURE.md` и `DECISIONS.md`. Если меняется
проверка — `TESTING.md` и CI. Заметное изменение фиксируется в `CHANGELOG.md`.

## Память

Локальная память не публикуется:

- `MEMORY.md` — постоянные решения;
- `memory/YYYY-MM-DD.md` — дневник;
- `knowledge/` — накопленные знания;
- `_progress.md` — временный план большой задачи.

Полные правила находятся в `instructions/memory-rules.md`.
