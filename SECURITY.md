# Безопасность

## Что проект защищает

- Клиент удаляет `HEYGEN_API_KEY` из окружения дочернего процесса.
- Работа разрешена только при OAuth-входе и подписочном типе оплаты.
- Создание аватара и видео требует отдельного явного подтверждения.
- Конфигурация, состояние рендеров и OAuth хранятся вне репозитория с правами
  только для владельца.
- Скачанный MP4 проверяется по размеру, длительности и декодированию.
- Каталог результата получает права `700`, готовый MP4 — `600`.
- Локальные файлы для загрузки должны существовать и иметь абсолютный путь.
- Фото и Digital Twin-видео проверяются по формату и лимиту 32 МБ до обращения к HeyGen.
- Диагностика не возвращает email, токены, внутренние ID и остаток кредитов.

## Что нельзя публиковать

Не добавляйте в Issues, логи или Pull Request:

- содержимое `~/.heygen/credentials`;
- реальные group ID, look ID, voice ID и video ID;
- фотографии, аудиозаписи и видео людей без их согласия;
- вывод команд, содержащий сведения об аккаунте или остатке кредитов.

## Как сообщить об уязвимости

Не публикуйте рабочий эксплойт и секреты в открытом Issue. Создайте приватный
Security Advisory в GitHub-репозитории проекта и опишите:

1. затронутую версию;
2. безопасные шаги воспроизведения;
3. возможное влияние;
4. предлагаемое исправление, если оно известно.

## Ограничения

Проект не обходит согласие Digital Twin, правила HeyGen и ограничения тарифного
плана. Пользователь отвечает за право использовать загружаемые лицо, голос и медиа.
