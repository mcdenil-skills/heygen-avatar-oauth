# Архитектурные решения

## 2026-09-02 — отдельное имя публичного скилла

**Контекст:** официальный HeyGen Skill и личная рабочая версия называются `heygen-avatar`.

**Решение:** публичная копия называется `heygen-avatar-oauth` и использует отдельные
каталоги конфигурации и состояния.

**Причина:** установка не должна заменять официальный или уже работающий личный скилл.

## 2026-09-02 — только OAuth и подписка

**Решение:** клиент всегда удаляет `HEYGEN_API_KEY` и продолжает работу только при
`billingType=subscription`.

**Причина:** пользователь должен расходовать кредиты существующего плана, а не случайно
включать отдельный API-биллинг.

## 2026-09-02 — живая запись главнее синтетического голоса

**Решение:** приложенное аудио передаётся как исходная речь пользователя. Каталожный
голос существует только для отдельного сценария генерации речи из текста.

**Причина:** выбор голоса не должен незаметно подменять настоящую запись.
