# Тестирование

## Быстрая проверка

```bash
npm ci
npm run verify
```

`verify` проверяет синтаксис обоих клиентов и запускает все тесты.

## Что покрыто

- удаление API-ключа из окружения;
- допуск только OAuth-подписки;
- безопасный вывод диагностики;
- каталог личных аватаров и стабильный group ID;
- выбор вертикального или горизонтального образа;
- создание из промпта, фото и Digital Twin-видео;
- согласие и ожидание готовности нового образа;
- каталог, подбор и прослушивание голосов;
- точная передача живой записи без синтеза;
- точная передача утверждённого текста в ElevenLabs;
- загрузка полученной ElevenLabs-дорожки в выбранный личный образ HeyGen;
- обязательное разрешение на синтез и рендер;
- проверенный кэш синтеза без повторного списания символов;
- повторное использование уже загруженного audio asset без второй загрузки;
- нормализация OGG/Opus, M4A/AAC, WAV и MP3;
- запрет платного вызова без явного подтверждения;
- продолжение существующего рендера без дубля;
- проверка готового MP4;
- закрытые права на каталог результата и готовый MP4;
- установка в изолированные каталоги Codex и Claude Code;
- отсутствие личных данных в публикуемых исходниках.

## Живая проверка

Обычные тесты не обращаются к HeyGen или ElevenLabs. Перед первой работой пользователь
выполняет только read-only диагностику `doctor`. Создание тестового аватара, синтез
речи или видео расходует лимиты и проводится отдельно после явного согласия владельца.
