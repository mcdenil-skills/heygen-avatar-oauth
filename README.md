# HeyGen Avatar OAuth

Неофициальный русскоязычный скилл для Codex и Claude Code: принимает вашу живую
аудиозапись, выбирает личный аватар нужного формата и создаёт готовый MP4 через
браузерный OAuth-вход в HeyGen. API-ключ не нужен.

## Чем отличается

- использует кредиты действующей подписки HeyGen, а не отдельный API-биллинг;
- передаёт в ролик именно приложенную запись голоса без повторного синтеза;
- поддерживает OGG/Opus, M4A/AAC, WAV, MP3 и видеофайлы с аудиодорожкой;
- хранит постоянного человека и отдельные образы для `9:16` и `16:9`;
- создаёт новые образы из промпта, фотографии или Digital Twin-видео;
- принимает JPG/PNG/WebP для фото и MP4/MOV/WebM для Digital Twin размером до 32 МБ;
- ждёт реальной готовности образа и поддерживает обязательное согласие Digital Twin;
- показывает варианты синтетических голосов с прослушиванием для отдельного сценария «текст → речь»;
- блокирует создание аватара или ролика без явного разрешения на расход кредитов.

## Что потребуется

- macOS или Linux;
- Codex либо Claude Code;
- Node.js 20 или новее;
- FFmpeg и FFprobe;
- HeyGen CLI 0.8.1 или новее;
- аккаунт HeyGen с подпиской и доступными кредитами.

Установите официальный HeyGen CLI:

```bash
curl -fsSL https://static.heygen.ai/cli/install.sh | bash
heygen auth login
```

Команда `heygen auth login` откроет браузер. Войдите в собственный аккаунт HeyGen.
Не пересылайте и не копируйте файл авторизации с другого компьютера.

## Быстрая установка

Скачайте репозиторий:

```bash
git clone https://github.com/Ntmib/heygen-avatar-oauth.git
cd heygen-avatar-oauth
```

Для Codex:

```bash
bash scripts/install.sh codex
```

Для Claude Code:

```bash
bash scripts/install.sh claude
```

Если используете обе программы:

```bash
bash scripts/install.sh both
```

После установки перезапустите Codex или Claude Code, если скилл не появился сразу.

Подробные инструкции: [Codex](docs/INSTALL-CODEX.md) и
[Claude Code](docs/INSTALL-CLAUDE-CODE.md).

## Проверка установки

Codex:

```bash
node "$HOME/.agents/skills/heygen-avatar-oauth/scripts/heygen-client.mjs" doctor
```

Claude Code:

```bash
node "$HOME/.claude/skills/heygen-avatar-oauth/scripts/heygen-client.mjs" doctor
```

Нормальный результат содержит `ok: true`, `credentialType: oauth` и
`billingType: subscription`. Скилл намеренно удаляет `HEYGEN_API_KEY` из окружения,
чтобы случайно не перейти на отдельный API-биллинг.

## Как пользоваться

После установки можно написать агенту обычным языком:

- «Покажи мои личные аватары»;
- «Запомни этот вертикальный и горизонтальный образ»;
- «Я прикрепил голосовое. Сделай из него вертикальный ролик с моим аватаром»;
- «Создай новый образ этого человека по фотографии»;
- «Покажи три русских голоса и дай их прослушать».

Создание аватара и видео расходует кредиты подписки. Скилл сначала получает явное
подтверждение пользователя и только затем разрешает одну платную операцию.

## Обновление

После получения новой версии репозитория повторите установку:

```bash
git pull
bash scripts/install.sh codex --force
# или: bash scripts/install.sh claude --force
```

Локальная конфигурация и OAuth-авторизация хранятся вне каталога скилла, поэтому
обновление их не перезаписывает.

## Безопасность и приватность

- В репозитории нет токенов, личных ID аватаров, голосов или аккаунтов.
- Диагностика не показывает email, токены, ID и остаток кредитов.
- OAuth хранится локально в стандартном каталоге HeyGen и не копируется установщиком.
- Фотографии, видео и аудио отправляются в HeyGen только по явной просьбе пользователя.
- Платный вызов без флага подтверждения блокируется до обращения к HeyGen.

Сообщить об уязвимости: см. [SECURITY.md](SECURITY.md).
