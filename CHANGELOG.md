## [1.0.0] — 2026-09-02

### Добавлено

- русскоязычный скилл для Codex и Claude Code;
- OAuth-вход без API-ключа и проверка подписочного типа оплаты;
- точный поток «живая аудиозапись → личный аватар → MP4»;
- стабильный человек и отдельные образы для `9:16` и `16:9`;
- создание образов из промпта, фото и Digital Twin-видео;
- проверка готовности и официальный consent-переход;
- выбор синтетического голоса с прослушиванием;
- безопасный установщик, тесты и GitHub Actions.
- предварительная проверка формата и размера фото/Digital Twin-видео;
- диагностика без email, токенов, внутренних ID и остатка кредитов.
- закрытые права доступа на каталог результата и готовый MP4.
